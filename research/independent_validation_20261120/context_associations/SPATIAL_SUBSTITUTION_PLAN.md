# Sign beside an animal versus sign in a written line

User-authorized continuation, 23 November 2026. Analysis rules recorded before computing candidate matches. Keep all work local while GitHub access is off.

The question is whether the same sign can move between a scene beside an animal and a written line while the rest of the inscription stays unchanged. A verified example would establish a spatial interchange, not the spoken sound or the proposed English meaning. A failure to find examples in this selected register would not reject interchangeable use throughout the script.

## Existing work and the extension

Cúper's `copper_4_picsign.py` and `copper_5_swaps.py` already investigate copper picture/sign alternatives and sign substitutions. `animal_4_pairs.py` compares shared text/name and animal labels; `animal_8_picturesigns.py` tests animal-shaped signs against animal species. `jobs/out/photo_pairs_A.md` already notes field boxes sometimes included in catalogue text. Bhaskar's 2024 paper supplies the frontal/dorsal classification and discusses transfers between positions. None of these is credited as our discovery. This extension tests an explicit exact-remainder criterion, retaining the independently published positions and requiring photographs for the other member of a putative spatial pair.

## Frozen comparison

1. Preserve all 33 illustrated source rows, uncertainties and PDF/workbook differences. Record what is beside/in the animal scene (F) and above/behind it (D). Do not assume every source 'dorsal' mark is a complete ordinary written line.
2. Primary search anchors require one unambiguous frontal sign, at least two unambiguous dorsal signs, no source-code disagreement, no disputed sign variant and no disputed frontality. The rest enter a separately labelled expanded discovery search. A scene-only object has no remaining text to match and cannot furnish this test.
3. Search both the existing Lipi transcription and the Mahadevan transcription for a line equal to D with precisely F inserted at one position. No substitutions, other deletions, phonetic equivalences, supplied words or tuned sign normalizations. Source order and its reversal are searched and explicitly distinguished. A hit in either is a discovery candidate, not evidence of reading direction.
4. In the Lipi channel use only an exact reversed-source Mahadevan sequence correspondence through the existing crosswalk's rank-1 sign mappings; retain all rank-1 alternatives. Do not pick a sign mapping to obtain a match. The direct Mahadevan channel avoids this numerical conversion. Cross-catalogue hits are not independent replications.
5. Exclude the anchor artifact itself. Full-line candidates must be complete seals or seal impressions, not copper picture faces or other object categories. A catalogue line must subsequently be checked against its photograph: a concatenation of a scene mark and a top line in a catalogue is not an independent inline example.
6. Report every candidate and its current proposed translation and actual findspot. Inspect recovered source photographs for the candidate targets. Only a photograph establishing F inside the written line while D is otherwise unchanged counts as a verified spatial interchange. Identical text alone does not establish a common seal die or common issuer.
7. Group copies/near-variant remainders before counting independent evidence. No held-out predictive success is claimed from a candidate search. If at least two independent confirmed families for the same target sign exist, freeze a rule from one family and evaluate another. Otherwise report a completed search and its actual outcome, without inventing a prediction denominator or p-value.

## Strongest rival and sensitivity search

The strongest rival is catalogue linearization: a supposedly inline target is still in the picture, but the transcription joins it to the top line. Photograph review directly distinguishes that explanation. Separately run a one-dorsal-sign sensitivity search and all uncertain/source-disputed anchors to expose attractive but inadmissible cases. These are discovery leads, never promoted by whichever coding produces a hit.

Also measure, descriptively, whether currently stored object transcriptions include the published frontal glyph, exclude it, or cannot be mapped. This diagnoses what existing occurrence counts represent; it is not semantic validation. No English meaning is changed in this experiment.
