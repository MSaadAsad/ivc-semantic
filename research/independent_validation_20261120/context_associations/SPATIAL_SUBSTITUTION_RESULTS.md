# A six-stroke/trident spatial parallel

The completed search and photograph review support one short pattern in two arrangements: M-1904 puts a six-stroke mark above a goat and the trident beside the animal; H-71, M-178, M-822 and M-1365 place six strokes and a trident together in text. The last example is a text face without an animal on that face. These are four photographed counterparts to one scene-layout object, representing one count-and-sign pattern.

Under Cúper's existing sign-390 proposal, the combined M-1904 design can provisionally be glossed **“six [cloth?]”**. The stored Lipi transcription remains `003-003`, with old English `3 3`; its separate field-object entry already records `S390`. Bhaskar's independent published description groups the strokes as Mahadevan 109, six, and identifies the field trident as 162. We do not overwrite the original number segmentation or add a newly authenticated sign to the core corpus. The actual measured correspondence is six strokes plus a trident, not an independently identified textile.

See the [illustrated results, English proposals and actual findspots](results/spatial_substitution/spatial_substitution.html).

## Search and outcomes

- All 33 illustrated layouts retained; 19 alternative workbook codings searched separately. The primary set contains six unambiguous single-frontal examples with at least two dorsal signs. None has an exact insertion counterpart in the eligible catalogue rows.
- Search covers 3,267 target rows: 1,338 Lipi rows convertible with the pre-existing rank-1 crosswalk and 1,929 direct Mahadevan rows carrying original strict source flags. Together they contain 1,870 distinct numerical sequences; catalogues overlap and these are not independent new inscriptions. Original flags exclude doubtful signs that the derived parsed table had cleaned.
- Expanded search yields 64 raw match records, reducing to 17 anchor/channel/target-line matches and three source references. Reversed searches and alternate source codings duplicate hits; no object count is inferred from 64.
- M-1904: four photographed spatial parallels supported; M-987 broken; M-1799 without recovered photo. Harappa contributes H-71; the other three supported inline objects are Mohenjo-daro. There is no independent city-level prediction or demonstrated common issuer.
- B-10: a workbook-only seven-stroke candidate matches M-1200's catalogue text. The illustrated PDF uses 110 and workbook 112; both are retained. M-1200 panel c clearly puts a trident in text, but its upper and lower marks do not allow this review to confirm a seven-stroke total. This remains unresolved, not a second validated count pattern.
- K-26: a leaf-like sign and jar yield numerical counterparts, but target photographs/object identities are unverified. The ambiguous source leaf variant and the old “King house” gloss are not promoted.

The six primary examples do not supply a longer-text counterpart, and no genuinely held-out prediction ran. The register is a selected collection of layouts, so zero primary matches cannot estimate interchange rates throughout the script. The single short successful pattern remains vulnerable to coincidental association or different functions of the same glyph. Four copies do not validate four meanings.

## What this contributes

Cúper already studies copper picture/sign substitutions and animal associations. His old metadata already identify M-1904's field trident; Bhaskar supplies the published spatial classification. The added work is an exact-remainder search with original uncertainty flags, image review that rules out catalogue concatenation for four actual counterparts, and a conditional whole-design interpretation using an unchanged existing key.

This makes a concrete spatial reading possible to investigate. It does not establish **cloth**, a sound, or Dravidian. A stronger extension needs the same interchange with longer distinctive texts or an independently verified second count. The seven-stroke example needs better imagery or primary epigraphic checking, not an assumption that a catalogue label overrides the photograph.
