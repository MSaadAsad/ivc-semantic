# Dholavira, Bagasra and Shikarpur physical-context recovery

This extends the existing corpus with published physical observations. It does not assume that Cúper never read the sources or treat already catalogued specimens as new inscriptions. Work and commits remain local under the user's current instruction; no GitHub fetch or push is authorized here.

## Sources and scope

- Frenez, Prabhakar and Bisht2016, *Administrative clay sealing technology from the Indus site of Dholavira: Preliminary observations*, author-uploaded conference presentation. Its public text gives61 Dholavira specimens and explicitly labels Bagasra BSR988/1188 as wall-peg sealings and Shikarpur SKP6506/1811 as string/rope examples. The functional results are preliminary. Direct PDF retrieval returned403; these four specimen observations can be recovered from the public text without claiming to have inspected unavailable figures.
- Bisht2015, *Excavations at Dholavira*, sealing register, printed pp309–329. A publicly readable copy supplies all61 numbered entries with accessions and reverse descriptions. It offers object-level evidence beyond aggregate conference figures. The file labelled Dholavira-Bisht2015.pdf at AncientPortsAntiques is a secondary illustrated commentary, not the original report; its speculative readings are not imported. The original ASI download was unavailable, so the source is the public report mirror and its ordinary viewer pages.

## Rules fixed before assigning new catalogue context labels

1. Retain all61 source entries, including non-script, illegible and uninformative fragments. Preserve duplicate accessions as separate source entries, rather than creating unique physical objects from a source inconsistency. Keep original period fields and qualify ambiguous uses such as pot mouth versus door fixture.
2. Recover source locations, depths and reverse observations. Keep factual observations separate from container/door interpretations. A textile imprint is packaging/contact evidence, not identified textile contents.
3. Search the existing catalogue using site and exact accession first. If accession is absent, retain grid/area/depth matches as **candidate crosswalks**. A unique excavation-context match does not automatically prove specimen identity. Do not assign one source object's label to every object from the same grid or depth.
4. Keep old signs and proposed readings unchanged. Do not invent transcriptions for source objects without them. No unverified source/corpus match enters a new predictive validation as established ground truth.
5. Export the four additional fastening specimens separately from Dholavira. Importing their physical observations does not mean their signs have been recovered. All additions distinguish source records, candidate context links, secure joins and new sign transcriptions.

Broad same-city/object-type, animal, seal-size and backing-category tests already exist. This task recovers missing context records and crosswalk evidence; no rerun of those tests is presented as novel. No sound value, translated word, exact package content or new physical die match is established by the source classification alone.
