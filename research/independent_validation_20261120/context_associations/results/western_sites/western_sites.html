Published physical context recovered for Dholavira, Bagasra and Shikarpur

23 November 2026 · local continuation; no GitHub push

Added 61 Dholavira register entries and four named fastening observations. These are published archaeological context records. No new sign transcription has been added. No source/corpus specimen match is silently accepted as proven.

What is actually new here?

The existing dataset has 69 Dholavira tag/sealing objects represented by 76 encoded faces. This expansion recovers the individual reverse-side observations, accessions, excavation locations, strata, depths and qualified attachment interpretations from Bisht 2015's full sealing register. The 61 source entries contain 60 distinct accession strings because 43884 appears twice. They are not 61 independently new inscriptions.

The 2016 functional presentation supplies 61 as an aggregate count and four explicitly named examples from other sites. It does not, in the recovered public text, provide the accession-level crosswalk needed to assign every functional category to a current inscription. The earlier excavation register supplies additional object-level evidence; the two 61-item populations are not presumed identical.

How the crosswalk is handled

Exact source accessions are searched first. Other candidates are retained with their actual agreement level: area+grid+depth, area+depth only, or lower resolution. Cases sharing only a depth or a general area do not receive definitive object labels. Multiple source candidates for one corpus object remain separate. Published classifications are not trained on proposed translations; object identity is a separate unresolved question.
